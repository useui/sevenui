<Component path="kbd/kbd-demo" />

## Installation

```bash
npx shadcn@latest add @sevenui/kbd
```

## Usage

```tsx
import { Kbd } from "@/components/ui/kbd";

<Kbd>⌘K</Kbd>;
```

## API reference

Plain `<kbd>`; no primitive. No props beyond `<kbd>`.
