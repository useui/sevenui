## Installation

```bash
npx shadcn@latest add @sevenui/separator
```

## Usage

```tsx
import { Separator } from "@/components/ui/separator";

<Separator />;
```

## API reference

Built on the [Base UI Separator](https://base-ui.com/react/components/separator)
primitive — all its props apply. SevenUI adds:

| Prop          | Type                             | Default        |
| ------------- | --------------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`      | `"horizontal"` |
