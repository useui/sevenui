## Installation

```bash
npx shadcn@latest add @sevenui/badge
```

## Usage

```tsx
import { Badge } from "@/components/ui/badge";

<Badge variant="outline">Badge</Badge>;
```

## API reference

Plain `<span>`; no primitive. SevenUI props:

| Prop      | Type                                                   | Default     |
| --------- | ------------------------------------------------------ | ----------- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline"` | `"default"` |
