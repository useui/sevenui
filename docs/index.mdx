SevenUI is a component library built exclusively on
[Base UI](https://base-ui.com) primitives. Components are installed as
source code into your project through the shadcn CLI — no runtime
package to depend on.

## Why SevenUI

- **Base UI only** — no Radix. Every component is built on
  [Base UI](https://base-ui.com) primitives, with nothing else underneath.
- **Drop-in shadcn compatibility** — works with the `shadcn` CLI and your
  existing `components.json` setup.
- **Source distribution via the registry** — components install as
  source files you own, not a package you depend on.
