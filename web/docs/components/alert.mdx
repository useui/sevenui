## Installation

```bash
npx shadcn@latest add @sevenui/alert
```

## Usage

```tsx
import { Alert, AlertDescription, AlertTitle } from "@/components/ui/alert";

<Alert>
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>You can add components to your app using the shadcn CLI.</AlertDescription>
</Alert>;
```

## API reference

Plain `<div>` elements with grid layout and semantic alert role. SevenUI exports:

| Component         | Description                                    |
| ----------------- | ---------------------------------------------- |
| `Alert`           | Container with grid layout and alert role.     |
| `AlertTitle`      | Title text with medium weight.                 |
| `AlertDescription` | Description text in muted foreground color.   |

| Prop      | Type                              | Default     |
| --------- | --------------------------------- | ----------- |
| `variant` | `"default" \| "destructive"`      | `"default"` |
