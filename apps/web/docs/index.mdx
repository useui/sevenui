SevenUI is a registry of 66 primitives built on
[Base UI](https://base-ui.com), each also available on
[UI SDK](https://ui-sdk.dev) with the same API. Primitives are installed
as source code into your project through the shadcn CLI — no runtime
package to depend on.

Composed, copy-and-go usage of these primitives lives in
[Components](/components); full pro sections and pages
live in [Blocks](/blocks).

## Why SevenUI

- **No Radix, anywhere** — the default flavour builds its interactive
  parts on [Base UI](https://base-ui.com); calendar, carousel, chart and
  resizable wrap four sanctioned, Radix-free libraries, and
  message-scroller and questionnaire build on `@shadcn/react`.
- **Two flavours, one API** — every primitive also ships on UI SDK
  (`@sevenui/ui-sdk/<name>`, a beta that needs React 19), where UI SDK
  replaces Base UI and also react-day-picker, embla-carousel and
  react-resizable-panels. Behaviour differs in places; each primitive's
  page lists how. Pro blocks are built on Base UI only. See
  [Choose a flavour](/docs/installation#choose-a-flavour).
- **Drop-in shadcn compatibility** — works with the `shadcn` CLI and your
  existing `components.json` setup.
- **Source distribution via the registry** — primitives install as
  source files you own, not a package you depend on.

## Coverage

SevenUI ships 66 primitives. The first 53 arrived across five waves:

- **Foundation wave** (15): button, badge, kbd, card, alert, separator,
  skeleton, spinner, aspect-ratio, textarea, table, breadcrumb, pagination,
  avatar, progress.
- **Form wave** (14): input, label, field, form, checkbox,
  radio-group, switch, toggle, toggle-group, slider, number-field,
  input-otp, select, combobox.
- **Overlay wave** (11): dialog, alert-dialog, sheet, drawer, popover,
  hover-card, tooltip, dropdown-menu, context-menu, menubar, toast.
- **Navigation & composite wave** (9): tabs, accordion, collapsible,
  navigation-menu, scroll-area, toolbar, meter, command, sidebar.
- **Third-party wrapper wave** (4): calendar, carousel, chart, resizable.

Navigation and composition are complete — tabs, menus, a shared-popup
navigation menu, a command palette, and a full sidebar system — with
zero Radix dependencies. No Radix, no cmdk, no vaul, no sonner: in the
Base UI flavour, every primitive that can be built on Base UI alone uses
Base UI and nothing else. The third-party wrapper wave adds exactly four
specialized, Radix-free libraries — react-day-picker, embla-carousel,
recharts, and react-resizable-panels — for the primitives that genuinely
cannot be built on Base UI alone, the same sanctioned choices shadcn
makes. Besides styling utilities, the only other dependency is
`@shadcn/react`, under message-scroller and questionnaire.

Form primitives use Base UI-native form handling. Libraries like
[react-hook-form](https://react-hook-form.com) plug into the `Field`
primitive's external-state props — see [Field](/docs/components/field).
