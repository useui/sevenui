## Installation

```bash
npx shadcn@latest add @sevenui/card
```

## Usage

```tsx
import {
  Card,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card";

<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
  </CardHeader>
  <CardContent>Card content goes here.</CardContent>
  <CardFooter>Card footer goes here.</CardFooter>
</Card>;
```

## API reference

Plain `<div>` elements with semantic layout. SevenUI exports:

| Component        | Description                                      |
| ---------------- | ------------------------------------------------ |
| `Card`           | Container element with border, shadow, and gap. |
| `CardHeader`     | Header section with grid layout.                 |
| `CardTitle`      | Title text with semibold weight.                 |
| `CardDescription` | Subtitle text in muted foreground color.        |
| `CardAction`     | Right-aligned action element.                    |
| `CardContent`    | Main content area with horizontal padding.       |
| `CardFooter`     | Footer section with flex layout.                 |
