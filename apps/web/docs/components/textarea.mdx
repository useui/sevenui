## API reference

### Textarea

Extends the native `<textarea>` element — no props beyond it.

| Prop           | Type                                     | Default |
| -------------- | ---------------------------------------- | ------- |
| `rows`         | `number` — initial height                | —       |
| `disabled`     | `boolean`                                | `false` |
| `required`     | `boolean`                                | `false` |
| `aria-invalid` | `boolean` — destructive border and ring  | —       |
