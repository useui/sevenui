## Installation

```bash
npx shadcn@latest add @sevenui/textarea
```

## Usage

```tsx
import { Textarea } from "@/components/ui/textarea";

<Textarea placeholder="Enter your message..." />;
```

## API reference

Plain `<textarea>`; no primitive. No props beyond `<textarea>`.
