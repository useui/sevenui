## API reference

### Separator

Extends the
[Base UI Separator](https://base-ui.com/react/components/separator)
primitive — all its props apply.

| Prop          | Type                             | Default        |
| ------------- | -------------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"`     | `"horizontal"` |
