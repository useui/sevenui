## Installation

```bash
npx shadcn@latest add @sevenui/skeleton
```

## Usage

```tsx
import { Skeleton } from "@/components/ui/skeleton";

<Skeleton className="h-4 w-40" />;
```

## API reference

### Skeleton

Extends `div` — no props beyond it. Size it with `className` to match
the content it stands in for.
