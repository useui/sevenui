## Installation

```bash
npx shadcn@latest add @sevenui/spinner
```

## Usage

```tsx
import { Spinner } from "@/components/ui/spinner";

<Spinner />;
```

## API reference

Renders the `lucide-react` `LoaderCircle` icon; no primitive. Accepts all `<svg>` props.
